## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| A check that cannot fail | Roughly **22** plan assertions across Phases 1-2 proved structurally incapable of passing or firing — a vacuity check testing `== 0` on a quantity that is never exactly 0; a mutation case asserting a violation name that a prior check always returns first; a sort whose deletion no test noticed because the fixture handed it pre-sorted input; a margin flag guaranteed true at every bar value; a `grep -rn 't.todo'` that matches `insert(todos` in the harness. | advisory | **Mutation-prove every gate**: break the thing deliberately, watch the gate go red, restore. Executors found most of these by doing exactly that. A green check is evidence only once someone has watched it fail. |
| Asserting the outcome instead of the reason | A test checking only "did it reject?" passes against an implementation that rejects everything. In plan 02-01, five of fourteen mutations left `check` still returning `false` — a *later* invariant caught the mutated state under a different name, so a bare-boolean assertion would have read green for all five. | advisory | Every rejection asserts its own specific code **and** that state was unchanged. Never `t.falsy(ok)` alone. |
| Trusting a prototype over the real engine | My Python prototype measured a 0.25% stall rate; the real engine measures 9.6-10.6% — a factor of 40. Cause: the prototype seated 10 players while the game seats 9 seekers (the hider does not play cards), which is amendment A3, which I wrote and did not carry into the prototype. | advisory | Re-measure against the shipped code before setting a bar from a prototype number. Research flagged this exact off-by-one as OQ-B. |
| `--filter` during a parallel wave | `tests/run.luau` loads **every** discovered spec before applying `--filter`, so a sibling's RED spec fails a filtered run that has nothing to do with it. Three executors hit this independently. Also produces alarming artifacts: `420 passed, 9 failed` then `429 passed, 0 failed` with no commit between. | advisory | Use a throwaway `tests/_wave_isolated_NN/` re-export with `--root`, deleted before the first commit. Logged as D-02-02. |
