<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| GitHub release assets → local toolchain | Third-party binaries and generated type definitions enter the build from the network |
| Repository → Studio live sync | Rojo decides which Studio-side instances are deleted during a sync |
| Developer machine → `rojo serve` HTTP port | A local HTTP server that a browser page could try to reach |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-09 | Tampering (supply chain, ASVS V10) | `rokit.toml`, `tools/types/globalTypes.None.d.luau` | mitigate | Exact `owner/repo@x.y.z` pins only (no ranges — asserted by `! grep -qE '[\^~*]' rokit.toml`); vendored type file pinned by byte size 677555 and sha256 `9ad7510…c609ee`, verified with `sha256sum -c` before commit (Task 2) |
