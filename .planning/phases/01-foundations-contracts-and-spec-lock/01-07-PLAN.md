**Lune datatype gap found during planning — you will hit this.** `@lune/roblox` exposes the
datatype constructors (`Vector3`, `CFrame`, ...) at runtime, but its shipped `types.d.luau` says
`-- TODO: Make typedefs for all of the datatypes as well...` and types only `Instance.new`. So

at the boundary and keep everything downstream typed:

```lua
local roblox = require("@lune/roblox")
local rbx = roblox :: any
local function vec3(x: number, y: number, z: number): any
	return rbx.Vector3.new(x, y, z)
end
```

Do not sprinkle `:: any` through the file and do not add `--!nocheck` (guard rule R1/R3 rejects it).
