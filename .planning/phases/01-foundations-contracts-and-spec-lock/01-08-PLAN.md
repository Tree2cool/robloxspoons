-- Roster admission (FOUND-08). PURE ZONE: no Roblox API. The adapter supplies the live count and
-- the configured cap; this module makes the decision.
export type Reason = "Ok" | "ServerFull" | "InvalidInput"
export type Decision = { admit: boolean, reason: Reason }

Implementation requirements:
- `decide(currentCount: number, cap: number): Decision`. Validate **both** arguments first:
  each must be a finite integer (`v == v`, not `math.huge` or `-math.huge`, `v % 1 == 0`) and
  `currentCount >= 0`, `cap >= 1`. Any violation returns `{ admit = false, reason = "InvalidInput" }`
  — never coerce, never `math.floor` a bad input into a plausible one.
- Admit when `currentCount < cap`, refuse with `ServerFull` otherwise.
- `canStartMatch(readyCount: number, min: number): boolean` applies the same input validation and
  returns `readyCount >= min`. It returns `false` rather than erroring on bad input, because a
  bad input must never start a match.
- Export nothing else. Any second predicate would create a second way to start a match.
- Reuse the finite check pattern from `src/shared/Net/Validate.luau`, but **do not require it** —
  that would be a cross-mount require from `src/server` into `src/shared` and guard rule R6 fails
  it. A four-line local helper is correct here; note the deliberate duplication in a comment.

Write `tests/core/admission.spec.luau` first, as an explicit boundary table over

| Threat ID | Category | Component | Disposition | Mitigation Plan |
