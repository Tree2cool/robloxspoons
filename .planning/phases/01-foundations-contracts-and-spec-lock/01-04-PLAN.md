**The three traps, stated exactly:**
1. `.luaurc` must set `"lintErrors": true`, or luau-lsp lint findings exit 0.
2. `--formatter plain` always returns 0 even with errors — it must never appear in a gate.
3. `luau-lsp analyze` defaults to `--platform roblox` and **never downloads** Roblox type

   engine-purity run needs `--platform standard` to see a type-only `Instance` reference.

**Config isolation mechanic you must use:** Luau resolves `.luaurc` by walking **up** from the
analysed file and the nearest value wins. So a fixture directory containing its own `.luaurc`
overrides the repo-root one. That is how the trap-1 counter-case is built — not with
`--base-luaurc`, which the root `.luaurc` would override.

**Assumption A1 is unverified and this plan is where it gets settled.** If

type-position references, and record the change in the SUMMARY.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
