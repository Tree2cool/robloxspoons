## Deviations from Plan

### Divergences found by executing the toolchain (D-17)

**1. [Rule 3 - Blocking] D-16 was wrong; Rokit cannot be used here**
- **Issue:** `api.github.com/repos/...` returns 403 in this container, so `rokit install` cannot work. The plan's environment fact ("api.github.com returns 200") was wrong.
- **Fix:** Tools installed by direct release-archive download (SHA256s above). `scripts/dev/bootstrap-tools.sh` was NOT created (the plan forbids it, and it was not needed; verified absent with `find`). D-16 corrected in CONTEXT.md (`4901495`).
- **Impact:** CI on GitHub Actions is unaffected; `rokit.toml` remains the version source of truth.

**2. [Rule 3 - Blocking] D-21 (new): `roblox.yml` must be generated outside this container**
- **Issue:** selene's bundled rustls has compiled-in roots, ignores `SSL_CERT_FILE` and the system trust store, and cannot verify the egress proxy CA (`invalid peer certificate: UnknownIssuer`). `curl` fetches the same URL fine, so this is selene's TLS stack, not a policy block. Building selene from source is also blocked (`static.crates.io` 403).
- **Fix:** The owner generated the file on Windows with direct network access and uploaded it (`4f011f1`). The STATE blocker from `67a96fb` is resolved.
- **Impact:** Any future bump of selene or the Roblox API surface needs the same out-of-container regeneration.

**3. [Discovery] Fourth exit-code trap: a missing sourcemap silently passes**
- **Issue:** With `src/shared/` missing, `luau-lsp analyze --platform roblox` printed `[ERROR] Failed to load sourcemap.json for workspace 'CLI'` and **still exited 0**. A missing or stale sourcemap silently degrades the entire type check while reporting green. This was not predicted by research. It is the most dangerous of the four traps.
- **Required follow-up:** The sourcemap step must be a hard prerequisite in every gate chain. Plans 01-10 and 01-11 (CI) must assert the sourcemap loaded (for example, fail on any `[ERROR]` line in the analyze output), not just that analyze exited 0. Recorded in 01-VALIDATION.md (now four traps).

**4. [Rule 3 - Blocking] `rojo build` does not create its output directory**
- `-o build/spoons.rbxl` fails unless `mkdir -p build` runs first. Every gate chain and CI step that builds needs that mkdir.

**5. [Rule 3 - Blocking] `src/shared/` must exist on disk**
- Rojo errors on a `$path` to a missing directory in both `sourcemap` and `build`. Fixed with `src/shared/.gitkeep` (`87262e0`), the plan's anticipated fallback. Plan 01-05 adds the first real file there.

**Total deviations:** 5, all environment or tooling facts discovered by execution. No scope change; no architectural decisions.
