<objective>
Write the privacy decision down as data: one frozen table saying who each message kind goes to, one
pure guard that throws when a private kind is handed to a broadcast method, one transform that
strips `ValveForcedPass` out of the public batch and turns it into a private notice, and the
`copy` assignment that gives the four copies of a rank their four suits.

Purpose: CARD-13 and CLAUDE.md rule 3. Guard R4 confines `FireClient`/`FireAllClients` to
`NetServer.luau`, so the question *"is any private data broadcast?"* reduces to *"which `Publisher`
method does the card shell call for each kind?"* — and that is a pure function of this file. That
reduction is the whole reason the privacy gate can be a unit test rather than a Studio session.

**D-18 is not an edge case.** `ValveForcedPass` fires in roughly **8% of rounds at a full roster**
(3.59-8.24% per cell at N=10, up to 15.8% at tighter pools), so the private cue is an ordinary
feature with real copy. The engine emits `ValveForcedPass` **immediately before** the `Passed` it
explains (`Engine.luau:368-375`), deliberately, so that every card movement has exactly one `Drew`
or `Passed`; the shell's job is to show the table the `Passed` and show only the affected player the
reason.

Output: `CardRouting.luau` and the routing gate.

```luau
--!strict
local Types = require("../engine/Types")

-- The seam that keeps CARD-13 testable. CardRouting and CardTable never touch a remote: guard R4
-- confines FireClient/FireAllClients to src/server/services/NetServer.luau, so the Roblox call is
-- in one file and the DECISION is in this one, as data.
export type Publisher = {
	toPlayer: (userId: number, kind: string, payload: unknown) -> (),
	toSeated: (kind: string, payload: unknown) -> (),
	toAll: (kind: string, payload: unknown) -> (),
}

export type Audience = "owner" | "seated"

CardRouting.KINDS = { "RoundStart", "Sync", "Notice", "Table", "Stall" }   -- frozen
CardRouting.AUDIENCE: { [string]: Audience } = {
	RoundStart = "seated",
	Sync = "owner",
	Notice = "owner",
	Table = "seated",
	Stall = "seated",
}                                                                          -- frozen
CardRouting.PRIVATE_KINDS: { [string]: true } = { Sync = true, Notice = true }  -- frozen

-- The guard NetServer's real toSeated/toAll call before firing anything. Extracted as a pure
-- function so a spec can exercise it directly; the Roblox adapter is then four lines with nothing
-- in it to test.
CardRouting.assertPublic = function(kind: string): ()   -- throws on a private or unknown kind
CardRouting.audienceOf = function(kind: string): Audience -- throws on an unknown kind

-- THE WHOLE PUBLISHER, ASSEMBLED HERE, so the guard a spec exercises is the guard that ships.
-- `NetServer.luau` cannot be loaded by Lune (it names `game:GetService`), so if it assembled the
-- three methods itself the mutation row "a real toAll('Sync') fails to throw" would be
-- UNREACHABLE: deleting assertPublic from NetServer would leave the suite green. Instead NetServer
-- supplies three minimal effect closures and this pure function assembles them, calling
-- assertPublic before both broadcast methods. `tests/card/netguard.spec.luau` then drives the
-- SHIPPED assembly with recording effects.
export type Effects = {
	fireToPlayer: (userId: number, kind: string, payload: unknown) -> (),
	fireToMany: (userIds: { number }, kind: string, payload: unknown) -> (),
	fireToAll: (kind: string, payload: unknown) -> (),
	seatedUserIds: () -> { number },
}
CardRouting.makePublisher = function(effects: Effects): Publisher
```

**`makePublisher`'s three methods, exactly:**

| Method | Behaviour |
|---|---|
| `toPlayer(userId, kind, payload)` | `effects.fireToPlayer(userId, kind, payload)`. No guard: `toPlayer` is the narrowest audience and a public kind sent to one player is not a leak |
| `toSeated(kind, payload)` | `assertPublic(kind)` **first**; then `effects.fireToMany(effects.seatedUserIds(), kind, payload)`. An empty seated list is a **no-op, not an error** — a stray publish before a round starts must not throw |
| `toAll(kind, payload)` | `assertPublic(kind)` **first**; then `effects.fireToAll(kind, payload)` |

Nothing may be fired when `assertPublic` throws: the guard runs before the effect, never inside a
`pcall`, and the spec asserts the recorder is empty on a throwing call.

```luau
export type FaceRecord = { cardId: number, rank: number, copy: number }
export type Notice =
	{ code: "ForcedPass", cardId: number }
	| { code: "Strike", strikes: number, owes: "Pass" | "Draw", cardId: number? }
	| { code: "Benched" }
export type PublicEvent =
	{ kind: "Drew", seat: number, cardId: number }
	| { kind: "Passed", seat: number, to: number, cardId: number }
	-- `faces` is the four RETIRED cards, which are public by design (they turn face up at the
	-- seat). `fifth` is DELIBERATELY ABSENT: the fifth card stays in the finisher's hand and its
	-- face is private. `lap` and every valve counter are server-side telemetry and never cross.
	| { kind: "Completed", seat: number, rank: number, faces: { FaceRecord } }
	-- `cause` is the FULL Types.RemoveCause, all three values. The engine's own completion path
	-- emits Completed and then SeatRemoved{cause="Completed"} (Engine.luau:249-254), so the
	-- published event must be able to carry it. The narrowing to "Disconnected" | "Benched"
	-- applies ONLY to the Remove INTENT the shell may issue, because Engine.apply throws on
	-- Remove{cause="Completed"} (Engine.luau:289-306). Two different types, one for each
	-- direction.
	| { kind: "SeatRemoved", seat: number, cause: "Completed" | "Disconnected" | "Benched", routedTo: number?, cards: number }
export type PrivateNotice = { seat: number, notice: Notice }
```

```luau
-- D-37's resolution: copy assignment is SERVER-SIDE. For each natural rank, the ids holding it are
-- visited in ascending order and numbered 1..4; jokers get copy 1. `State.rankOf` is fixed for the
-- whole round (grep over src/server/engine finds no reassignment), so this is computed ONCE at the
-- deal and never recomputed. It leaks nothing: within a rank the relative id order is uniformly
-- random because ids are shuffled deck positions, and a client only ever receives the record for a
-- card it holds.
CardRouting.assignCopies = function(rankOf: { number }, ranks: number): { number }

-- Splits one Engine.apply event list into what the table sees and what individual seats are told.
-- `copyOf` is the table from assignCopies; it is needed only to build Completed.faces.
-- PURE: no clock, no roster, no userId. CardTable owns the seat -> userId lookup (and must, because
-- the roster is state and this file holds none).
CardRouting.split = function(events: { Types.Event }, copyOf: { number }): ({ PublicEvent }, { PrivateNotice })
```

**`split`'s rules, exhaustive over `Types.Event`:**

| Engine event | Public batch | Private notice |
|---|---|---|
| `Drew{seat,cardId}` | emitted unchanged | — |
| `Passed{seat,to,cardId}` | emitted unchanged | — |
| `Completed{seat,rank,retired,fifth}` | `{kind="Completed", seat, rank, faces}` with one `FaceRecord` per id in `retired`; **`fifth` dropped** | — |
| `SeatRemoved{seat,cause,routedTo,cards}` | emitted unchanged | — |
| `ValveForcedPass{seat,cardId,to,lap}` | **NOTHING.** Stripped entirely; the table sees the `Passed` the engine emitted beside it | `{seat, notice={code="ForcedPass", cardId}}` |

`split` must **error by name** on an event kind it does not recognise, so a future engine event
cannot silently become invisible to the UI or silently leak. That error is the exhaustiveness
guarantee, and the spec drives it with a made-up kind.
