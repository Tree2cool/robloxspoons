<objective>
Close the two guard holes `04-CONTEXT.md` D-37 and D-38 found by reading the guard source, prove
both with fixtures, and write this phase's device rows into `MANUAL-CHECKS.md` before any execution
begins.

Purpose: D-38 is Non-Negotiable Rule 1 — *"what makes no-pay-to-win true rather than promised"*.
`guardedNamePrefixes` matches a file's basename by prefix, so naming the pure core `CardTable.luau`
covers **exactly that one file**: `CardRouting`, `CardService`, `IdleClock`, `StallDetector`,
`Flourish` and every client UI module would have no import-path check to cosmetics or shop code at
all. D-37 is the other half: guard R5 is a **raw plain-text substring scan** over whole file text
(`check-guards.luau:528-532`), so adding `rankOf` to `secretNames` while a shared module names it
*even in a comment explaining the rule* fails the build. Both are one-line changes here and
expensive archaeology in Phase 7.

The `MANUAL-CHECKS.md` rows are in this plan, in wave 1, deliberately: **four of the five ROADMAP
success criteria for this phase are device-dependent** and this container has no Studio and no
phone. Writing the rows first is what stops a later plan from quietly claiming a criterion a
machine cannot evaluate.

Output: an extended `zones.luau`, three new guard fixtures with cases, and M-11..M-17.
</objective>
