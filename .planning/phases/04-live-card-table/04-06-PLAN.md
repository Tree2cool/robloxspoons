<objective>
Build the AFK clock: the per-seat deadline and strike bookkeeping that sits **beside** the engine,
never inside it, and that decides when to auto-pass, when to strike and when to bench.

Purpose: CARD-16 under its two Gate G1 constraints and five locked decisions.

**D-15 is the single most likely thing in this phase to be implemented wrong**, and the plan says so
because the failure is invisible: without it, the ~8.3 s start-up ramp at a full table strikes far
seats for waiting on cards that have not reached them yet, which looks like a tuning problem and is
actually a correctness one. The clock runs **only** while the seat has a legal action — hand at 4
with a non-empty inbox, or hand at 5 — and pauses otherwise.

**D-35 is enforced in the type system, not only in a test.** At hand 4 the expiry yields a strike
and no card movement. There is no `AutoDraw` command variant, so "an auto-draw fires" is a type
error as well as a test failure. The reason is sharper than symmetry: four of a kind is checked
**only on draw**, so an auto-draw could hand an absent player a completion — and with it the
four-of-a-kind bonus and the kept placement bonus. The game would be paying someone for being away.
**The Gate G1 sweep modelled the deadline at hand 5 only, so no simulator result speaks to hand-4
behaviour at all; do not cite the sweep as evidence here.**

Output: `IdleClock.luau` and the CARD-16 gate.
</objective>

```luau
--!strict
local Types = require("../engine/Types")

-- What the core needs to know about one seat. CardTable projects this out of the engine State after
-- every successful apply; this file never sees a State, a hand's CONTENTS or a card id, except for
-- the explicit `pickUniform` call.
export type SeatView = { live: boolean, handSize: number, inboxSize: number }
export type View = { [Types.SeatId]: SeatView }

export type Owes = "Pass" | "Draw"

-- THE COMMAND VOCABULARY. There is deliberately NO AutoDraw variant (D-35): an auto-draw could
-- hand an absent player a completion, because four of a kind is checked only on draw. Adding one
-- must be a type error, not merely a failing test.
export type Command =
	{ kind: "AutoPass", seat: Types.SeatId }
	| { kind: "Strike", seat: Types.SeatId, strikes: number, owes: Owes }
	| { kind: "Bench", seat: Types.SeatId }

export type Deps = {
	autoPassDeci: number,  -- 80 at the shipped config; the value, never the seconds
	maxStrikes: number,    -- 3 (D-17)
}

export type IdleClock = {
	-- Call after EVERY successful apply, with the whole view. `playerActedSeat` is the seat whose
	-- OWN accepted client action caused this apply, or nil. It is nil for a server-originated
	-- auto-pass, for a valve forced pass and for a bench: D-17 resets the strike count on any REAL
	-- action, and a card the server moved for you is not one.
	sync: (self: IdleClock, view: View, nowDeci: number, playerActedSeat: Types.SeatId?) -> (),
	-- Time-driven behaviour, as returned commands. The adapter applies each OUTSIDE any apply and
	-- publishes afterwards (CLAUDE.md rule 6). Never schedule a per-seat timer.
	tick: (self: IdleClock, nowDeci: number) -> { Command },
	forget: (self: IdleClock, seat: Types.SeatId) -> (),
	deadlineDeci: (self: IdleClock, seat: Types.SeatId) -> number?,
	strikesOf: (self: IdleClock, seat: Types.SeatId) -> number,
	owesOf: (self: IdleClock, seat: Types.SeatId) -> Owes?,
}

IdleClock.new = function(deps: Deps): IdleClock

-- D-15, written ONCE, exported so the spec drives the real predicate and not a copy of it.
IdleClock.legal = function(seat: SeatView): boolean
	-- (handSize == 4 and inboxSize >= 1) or handSize == 5, and the seat must be live

-- D-14, LOCKED and not a tuning knob. A card drawn UNIFORMLY AT RANDOM from the hand. The
-- helpful-looking "auto-pass your worst card" is the player's own greedy choice, which makes the
-- deviation the Gate G1 sweep measured exactly zero and means its auto-pass numbers transfer
-- nothing to the shipped game (02-CONTEXT amendment A7-CORRECTION). `rng` is injected; this file
-- creates no randomness of its own.
IdleClock.pickUniform = function(hand: { Types.CardId }, rng: any): Types.CardId
```

**Transition rules (`sync`), exhaustive:**

| Situation | Effect |
|---|---|
| seat not in the view, or `live == false` | entry dropped (same as `forget`) |
| `legal(seat)` and no deadline armed | arm: `deadline = nowDeci + autoPassDeci` |
| `legal(seat)` and `seat == playerActedSeat` | re-arm `deadline = nowDeci + autoPassDeci`; `strikes = 0` |
| `legal(seat)` and armed and not the actor | **leave the deadline alone.** A card arriving in someone's inbox must not refresh their window |
| `not legal(seat)` | disarm (`deadline = nil`); `strikes` is **kept**, not cleared — the clock pauses, the record does not |
| `seat == playerActedSeat` and not legal | `strikes = 0` (a real action still forgives) |

**Expiry rules (`tick`), for every armed seat with `deadline <= nowDeci`:**

| Seat owes | Commands emitted, in this order |
|---|---|
| `Pass` (`handSize == 5`) | `AutoPass{seat}`, then `Strike{seat, strikes, owes="Pass"}`, then `Bench{seat}` if `strikes >= maxStrikes` |
| `Draw` (`handSize == 4`, inbox non-empty) | `Strike{seat, strikes, owes="Draw"}` only — **no card moves (D-35)** — then `Bench{seat}` if `strikes >= maxStrikes` |

In both cases `strikes` is incremented **before** the `Strike` command is built (so the command
carries the new count, matching the copy `Strike {n} of 3`) and the deadline is **re-armed** to
`nowDeci + autoPassDeci`. Seats are visited in ascending `SeatId` so a multi-seat expiry in one tick
is deterministic. `AutoPass` carries no card: plan 04-12's `CardTable` calls `pickUniform` with the
real hand and its own `Rng`, because the hand's contents are state this file deliberately does not
hold.

**The bench path:** plan 04-12 turns `Bench{seat}` into `Engine.apply(state, {kind="Remove",
seat=seat, cause="Benched"})` — the **one generic seat-removal operation** (CLAUDE.md rule 8), so
the benched seat's cards route to the successor and are never destroyed. `Engine.apply` **throws**
on `cause = "Completed"`; the shell's type must exclude it.

**Honest consequence of the deci boundary, recorded (assumption A5):** `autoPassDeci = 80` is a
bound on the *configured* value. Flooring a continuous clock and sweeping at 10 Hz realises roughly
**7.9 s to 8.2 s** of wall time — about +-0.1 s on arming and up to +0.1 s of sweep lateness. That
is below the simulator's model noise and below platform jitter. If the owner later reads the ceiling
as a hard wall-clock bound, the fix is `autoPassDeci = 79` in `CardService`, with no change here.
