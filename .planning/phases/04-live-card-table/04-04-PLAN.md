<objective>
Create the phase's new pure zone and its first module: the card face vocabulary. Engine rank
integers become real playing-card rank glyphs, the four copies of a rank become the four suits, and
"greyscale must survive" becomes a falsifiable test instead of a reviewer's opinion.

Purpose: D-21, D-22 and D-24. The engine has **no suits** — a rank is an integer and
`ranks = seated seekers + 3`, so a round uses between 5 ranks (3 players) and **12 ranks
(10 players)**, four copies each, plus one joker. Twelve fits inside A,2..10,J,Q,K, so a round is a
subset of a standard deck. D-24 turns colour-blind safety into a test: **shape and glyph carry all
rank and copy identity; colour is decorative only.** That covers total achromatopsia, which a tuned
palette cannot. D-23 is load-bearing beyond art: `CardPool.JOKER_MODE` is a **live flag**, so the
same card means two different things depending on configuration and the face must be able to say
which.

This is also the plan that registers `src/shared/Card` in `pureZones`, which is what makes the
"pure" claim in every later shared-card plan enforceable.

Output: `Faces.luau`, the registered zone, and the CARD-19 gate with its mutations.
</objective>

```luau
--!strict
export type Suit = "spade" | "heart" | "club" | "diamond"
export type JokerMode = "Wild" | "Blocker"

-- The DRAWN asset for a suit. Exactly one of `glyph` / `sprite` is used at render time, chosen
-- once by `PIP_SOURCE`; both are declared so the greyscale gate can assert distinctness of
-- whichever the renderer actually draws (UI-SPEC layer 2).
export type Pip = {
	suit: Suit,
	silhouette: string, -- the shape name a reviewer names in the greyscale check
	glyph: string,      -- the codepoint attempt (UI-SPEC pip order of attempts, step 1)
	sprite: { x: number, y: number, w: number, h: number }, -- the 4-cell sheet cell (step 2)
	isRedByDefault: boolean, -- DECORATIVE ONLY. Never part of an identity key.
}

export type Band = { text: string, shape: string }

export type Face = {
	isJoker: boolean,
	rankGlyph: string,  -- "" for a joker
	pip: Pip?,          -- nil for a joker
	band: Band?,        -- joker only
	key: string,        -- the identity key; injective across all 50 faces
}

Faces.MAX_RANKS = 12            -- ranks = seated seekers + 3, seats 2..9 live -> 5..12
Faces.JOKER_RANK = 0            -- mirrors the engine's Types.JOKER_RANK; the spec is the drift test
Faces.PIP_SOURCE = "glyph"      -- "glyph" | "sprite"; flipped by M-16 if the glyphs fail on a phone

-- D-21 / D-22: engine rank r in 1..12 -> RANK_LADDER[r]. Ordered by VISUAL DISTINCTNESS, so a
-- 3-player round (5 ranks) uses the five most dissimilar glyphs and the confusable 6/8/9 trio
-- enters last. "6" is never used: the 13th rank is unreachable because max ranks is 12. The
-- mapping does not depend on round size, so a given integer never changes glyph mid-round.
Faces.RANK_LADDER = { "A", "K", "Q", "J", "10", "7", "4", "2", "5", "3", "9", "8" }  -- frozen

Faces.SUIT_OF_COPY = { "spade", "heart", "club", "diamond" }  -- frozen; copy 1..4
Faces.PIP: { [Suit]: Pip }                                    -- frozen
Faces.JOKER_MODES = { "Wild", "Blocker" }                     -- frozen
Faces.JOKER_BAND: { [string]: Band }                          -- frozen
Faces.JOKER_EXPLAINER: { [string]: string }                   -- frozen; strip copy, <= 34 chars

Faces.glyphOf = function(rank: number): string            -- errors outside 1..MAX_RANKS
Faces.suitOf = function(copy: number): Suit               -- errors outside 1..4
Faces.faceOf = function(rank: number, copy: number): Face -- rank 0 is a joker; copy ignored there
Faces.jokerFaceOf = function(mode: string): Face          -- errors on an unmapped mode
Faces.keyOf = function(rank: number, copy: number): string

-- The self-audit. Takes the tables as ARGUMENTS so the spec can drive it with deliberately
-- collapsed copies: the mutation is an injected broken dependency, never a source edit
-- (the tests/engine/valve.spec.luau convention). Returns the problems AND the number of faces
-- actually visited, so a vacuous audit fails.
export type AuditTables = {
	ladder: { string },
	suitOfCopy: { string },
	pip: { [string]: Pip },
	jokerModes: { string },
	jokerBand: { [string]: Band },
	pipSource: string,
}
Faces.TABLES: AuditTables                                        -- the real tables, as one value
Faces.audit = function(tables: AuditTables): ({ string }, number)
```

**`Faces.audit` must report, each with its own distinguishing message:**

| Problem | Message substring |
|---|---|
| two faces share an identity key | `duplicate identity key:` |
| two suits share a `silhouette` | `duplicate silhouette:` |
| two suits share the DRAWN asset actually selected by `pipSource` (the `glyph`, or the four `sprite` numbers as a tuple) | `duplicate drawn asset:` |
| a `copy` in 1..4 has no suit, or a suit has no `Pip` entry | `unmapped copy:` / `unmapped suit:` |
| a mode in `jokerModes` has no `jokerBand` entry | `unmapped joker mode:` |
| two joker modes share a band `text` **or** share a band `shape` | `duplicate joker band:` |
| the ladder has a duplicate glyph, or fewer than `MAX_RANKS` entries | `duplicate rank glyph:` / `short ladder:` |

**Identity key, and what is NOT in it (D-24):** the key is `(rankGlyph, silhouette)` rendered as
`"{rankGlyph}/{silhouette}"`, and a joker's is `"JOKER/{band.text}"`. **Colour is not in the key.**
`isRedByDefault` exists only so the renderer can tint; it must never be read by `keyOf` or by
`audit`. Both joker modes differ in **text AND shape** (`WILD` on a solid star, `BLOCK` on the same
star with a diagonal bar), which is what keeps the joker greyscale-safe.

**Visited count:** `audit` visits `#ladder * #suitOfCopy + #jokerModes` faces = `12 * 4 + 2 = 50`
at the real tables. The spec asserts the returned count is exactly 50.
