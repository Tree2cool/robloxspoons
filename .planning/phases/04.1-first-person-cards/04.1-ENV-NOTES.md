# Phase 04.1 — environment facts, measured

Three claims in the plan set are about the toolchain rather than the game. All three were checked
by running them on 2026-11-10. **One was right for the wrong reason**, which is recorded because a
wrong reason sends the next person hunting the wrong thing.

## 1. `lune -e` does not exist — CONFIRMED

`lune --help` lists exactly two subcommands:

```
run    Run a script
list   List scripts available to run
```

There is no `-e` / `--eval`. Six verify commands in the first draft used it and would have failed
at the first wave that ran them.

## 2. "scripts piped to `lune run -` cannot `require`" — RIGHT CONCLUSION, WRONG REASON

The real behaviour, measured:

| | `require("@lune/fs")` | `require("./scripts/ci/lex")` |
|---|---|---|
| piped, `lune run -` | **works** | **fails:** `require is not supported in this context` |
| real file, `lune run f.luau` | works | works |

**It is RELATIVE requires that fail from stdin, not requires in general** — there is no script path
for a relative specifier to resolve against, while a built-in alias needs none.

The practical consequence is unchanged: any check that needs `scripts/ci/lex` (every
comment-stripping scan) must live in a real committed file, which is why `scripts/dev/scan.luau`
exists. But the stated reason mattered: someone reading "cannot require" would conclude a piped
script is useless for everything, when a built-in-only script piped to `lune run -` is fine.

## 3. Returning `nil` from `buildDealGeometry` retires the 2D deal — CONFIRMED

`src/client/ui/CardFlourish.luau:379-381` reads:

```lua
local geometry = stage.deal()
if geometry == nil or #geometry.to == 0 then
    return
end
```

So the 2D deal flourish already opens with a nil guard. **Returning `nil` makes that path dark with
no edit to the frozen file**, and the flourish driver, the 1.5 s cut-off and the CARD-18 seam are
all untouched. This is what makes "the hand-build IS the deal" implementable without a double deal
and without reopening a frozen file — worth knowing precisely, because the alternative would have
been a Phase 7 conflict over `CardFlourish`.
