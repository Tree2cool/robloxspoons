<objective>
Regenerate the reference map so that **every** authored default spot passes the real placement
rules, with real margin above the 16-spot minimum, and prove it spot by spot.

Purpose: D-15 and D-17. Open Question 1 was resolved **STRICT** by the owner: every authored default
spot must pass, one issue per failing spot, and any failure fails the build. Research then measured
that the confirmed constants leave exactly **16 of 18** surviving with **zero spare**, so D-15 fires
immediately: *if the real rules cull the graybox below 16, fix the map — never the rules, never the
minimum.* The rules express HIDE-06 and 16 is a contract (MAP-03); if the reference map cannot
satisfy both, the map is wrong. This keeps the rules a statement about findability rather than a
curve fitted to one map, which matters more than usual because this phase gates Phase 7a authoring
five more maps against these same rules.

`Spot08` (the shelf centre) is **genuinely unfindable** — blocked by line of sight from every floor
position within 12.36 studs — and must not be re-authored in place. `Spot09` (the shelf east edge)
needs an effective range of 6.54 against the shipped 5.5. Both go. The **shelf geometry stays**: it
is the "out of reach" corpus fixture and plan 03-05's corpus probes it at coordinates where no spot
is authored.

This plan runs **before** the validator's placement stage is wired (plan 03-08) deliberately. It
calls `SpoonPlacement` directly, so the map is already correct by the time
`scripts/verify.luau`'s `validate-map` step starts running the placement rules — otherwise the
verify chain would be red for a whole wave.

Output: 21 authored spots that all pass, a per-spot margin table in the suite, the real map's slope
negative control, and the D-09 wall-clock cap for the reference map.
</objective>
