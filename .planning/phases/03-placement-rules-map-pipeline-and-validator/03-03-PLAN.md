<objective>
Build the exact geometry layer: one pure module that turns a pose into an oriented bounding box and
answers three questions about it — does a point sit inside (and how far away is it), does a segment
cross it, and where does a vertical line enter and leave it.

Purpose: D-01. The rules see geometry as oriented bounding boxes built from the `MapContract.Node`
snapshot, with our own segment-vs-OBB raycast and walkability maths, because `src/server/core` is a
pure zone and `Workspace:Raycast` is not available there. **One implementation serves CI and
runtime** — that is what makes MAP-02's "the real placement rules" literally true rather than
aspirational. The accepted limitation, stated plainly: this is *our* model of collision, not
Roblox's. Boxes are exact; meshes and CSG are only as correct as the snapshot makes them.

This module is where the phase's silent-wrongness risk concentrates. The algorithm is textbook (the
Kay-Kajiya slab method, about 60 lines); the risk is a degenerate case that returns "no hit" by
accident. Division by zero yields `inf`, and when the segment origin sits exactly on a slab plane
`0 * inf = NaN`, which compares false everywhere and silently reports no hit. Each degenerate case
gets a named test, and the whole thing gets a differential fuzz against a brute-force sampler.

Output: `src/server/core/Obb.luau` and a spec whose fuzz properties would catch a sign error in any
of the three routines.
</objective>

```luau
--!strict
local MapContract = require("./MapContract")

type Vec3 = MapContract.Vec3

-- An oriented bounding box in pure data. `axis[k]` is the unit basis vector for local axis k
-- (k = 1 right, 2 up, 3 look) stored component-wise in three flat arrays so a hot loop never
-- indexes a table of tables. `h[k]` is the half extent along axis k. The world AABB is
-- precomputed because the slab test prefilters against it.
export type Box = {
	name: string,
	cx: number,
	cy: number,
	cz: number,
	ax: { number }, -- ax[k] = x component of axis k
	ay: { number }, -- ay[k] = y component of axis k
	az: { number }, -- az[k] = z component of axis k
	h: { number },
	minx: number,
	miny: number,
	minz: number,
	maxx: number,
	maxy: number,
	maxz: number,
	standable: boolean, -- true only for a block-shaped collidable Part (research assumption A4)
}

export type Index = {
	cellSize: number,
	minx: number,
	minz: number,
	nx: number,
	nz: number,
	buckets: { { number } }, -- bucket[j * nx + i + 1] = list of box indices overlapping that bucket
	boxes: { Box },
}
```

Exported functions, exact signatures:

```luau
Obb.GEOM_EPSILON: number                   -- 1e-3 studs. A LENGTH tolerance, separate from MapValidator's LOOK_EPSILON
Obb.fromPose(name: string, centre: Vec3, size: Vec3, look: Vec3, up: Vec3, standable: boolean) -> Box
Obb.isOrthonormal(look: Vec3, up: Vec3, epsilon: number) -> boolean
Obb.distanceToPoint(box: Box, x: number, y: number, z: number) -> number   -- 0 when inside
Obb.segmentHits(box: Box, px: number, py: number, pz: number, qx: number, qy: number, qz: number, inflate: number) -> boolean
Obb.columnSpan(box: Box, x: number, z: number) -> (number?, number?, number)  -- lo, hi, nyTop
Obb.newIndex(boxes: { Box }, cellSize: number) -> Index
Obb.queryIndex(index: Index, minx: number, minz: number, maxx: number, maxz: number, out: { number }) -> number
```

**Basis derivation, verified against the committed graybox `Ramp`.** The third axis is
`right = look x up` (D-02). The Ramp's CFrame is `CFrame.new(...) * CFrame.Angles(0, 0, -angle)`
with `angle = atan(6.5 / 14) = 24.9047` degrees, which gives `look = (0, 0, -1)` and
`up = (0.42111206, 0.90701294, 0)`. Then
`look x up = (0.90701294, -0.42111206, 0)`, which is exactly the part's `RightVector` as measured
under Lune 0.11.1. `axis[1] = right`, `axis[2] = up`, `axis[3] = look`, with
`h = { size.x / 2, size.y / 2, size.z / 2 }` — the slab is symmetric so the sign of the look axis is
irrelevant.

**World AABB:** `half_component = sum over k of abs(axis[k].component) * h[k]`, then
`min = centre - half`, `max = centre + half`.

**Epsilon discipline (research, non-negotiable).** `GEOM_EPSILON = 1e-3` studs is the only length
tolerance in the phase; never write a bare `1e-6` in a length comparison. Every **acceptance**
comparison shaves it (`d <= limit - GEOM_EPSILON`) and every **rejection** comparison adds it, so
every borderline outcome falls on the rejecting side, consistent with D-11's bias. The float32
snapshot error is about 1e-7 on a unit vector and about 1e-5 on a 100-stud position, four orders of
magnitude below 1e-3. The parallel-slab branch uses a hard `1e-12` guard on the **direction
component** — that is a divide-by-zero guard, not a length tolerance, and it is the one place a
different constant is correct.

**D. Two differential fuzz properties.** This is the part that catches a sign error nobody thought
to write a unit test for.

```luau
	t.fuzz("segmentHits agrees with a brute-force sampler over random oriented boxes", {
		iterations = 400,
		gen = function(rng, i)
			-- gen is the ONLY consumer of the shared rng (the Fuzz driver's rule). Build a random
			-- box with a random orthonormal basis from two random angles, and a random segment.
			-- Return everything the check needs so `check` is a pure function of the value.
			return { ... , i = i }
		end,
		check = function(v)
			-- Brute force: sample the segment at 4000 evenly spaced points and ask
			-- distanceToPoint(box, point) <= 0 for any of them.
			-- The two answers may legitimately differ ONLY in a band of width GEOM_EPSILON plus the
			-- sampling step around the surface. Assert agreement OUTSIDE that band, and count how
			-- many hits and how many misses were generated.
		end,
	})
```

The orthonormal basis generator: pick a random yaw and a random roll, build `look` from the yaw and
`up` from the roll about `look`, then renormalise. Assert inside `gen` that the produced basis
passes `Obb.isOrthonormal(look, up, 1e-9)`, so a broken generator fails loudly instead of producing
nonsense the property then "agrees" with.
