<objective>
Gate G2 is the phase's exit and it unlocks Phase 7a authoring five maps against these rules. The
evidence is complete and automated; the decision is the owner's.

Purpose: ROADMAP Gate G2, and the project's own convention that a gate which unlocks a body of work
is signed off by a human looking at the numbers. Phase 2 did the same for Gate G1 (plan 02-12, not
autonomous). This plan is deliberately separate from `03-10` because a checkpoint and the work it
reviews do not belong in the same plan.

There are also two blocking manual checks to settle, and they are the **same Studio session**:

- `M-08` — the place's `CharacterMaxSlopeAngle` must be at or above `MAX_SLOPE_DEGREES = 30`. The
  platform default is 89, so it almost certainly passes, but it is a Creator-Hub setting the
  repository cannot read, in the same class as `Players.MaxPlayers` (M-05) and the FOUND-07
  persistence toggle. It needs one reading in Studio.
- `M-10` — the v2 21-spot reference map must load through `MapLoader` and validate clean in a real
  Studio session. This is the **only** check that can observe value-level parity between the two
  snapshotters: CI's gate 8 compares their key sets, but `MapLoader` cannot run under Lune, so the
  two are never fed the same input. `MapLoader` runs the same `MapValidator.validate` over its own
  snapshot, so a divergence large enough to change a verdict surfaces here as a validation failure.
  It is also the re-run `M-06` needs — M-06 is signed against the ContractVersion 1 18-spot map.

Output: the owner's verdict appended to `03-G2-REPORT.md`, and `M-08` and `M-10` each resolved one
way or the other.
</objective>
