<objective>
The one client wiring file, the spectator camera, and the boot line.

Purpose: `CardClient.luau`'s header sets this file's standard in its own words — *"THE ONE WIRING
FILE ... Everything it does is plumbing: any `if` that decides a game outcome belongs in
src/shared/Card/. That sentence is this file's standard."* `HuntClient` has an easier job than
`CardClient` (no reducer, no prediction, no hand) and one harder constraint: **the messages it
handles carry hidden positions**, so a bug here is a HUNT-01 bug rather than a cosmetic one.

Two specific hazards:

**A yielding handler is worse here than in the card stream.** V-12 guarantees handler *start* order
only. A slow `SpoonVisible` handler overtaken by the `SpoonHidden` that supersedes it leaves the
client rendering a spoon the server has already hidden — a reveal outliving its entitlement, which is
the exact failure D-01 exists to prevent.

**D-17, the one place this phase declines a stated owner preference.** The owner said "the game
should be first person" and then clarified it as the *card* phase, where the argument was worked
through and the 48 px objection resolved by locking the camera. **None of that reasoning transfers to
the hunt**, which is free movement across a parkour map. So the hunt keeps the standard camera, this
plan builds no first-person hunt, and the decision is raised rather than buried. If the owner wants
it, it is its own phase — it interacts with glint visibility, line of sight and the plausibility
check all at once.

Output: `SpectateCamera.luau`, `HuntClient.luau` and one boot line.
</objective>

**The seven handlers, and nothing else:**

| Kind | What the handler does |
|---|---|
| `HuntStart` | `remaining:show()`. Nothing else. The reveals arrive as their own messages |
| `SpoonVisible` | `view:show(p.id, p.x, p.y, p.z)` |
| `SpoonHidden` | `view:hide(p.id)` |
| `SpoonsRemaining` | `remaining:setCount(p.count)` |
| `ClaimOk` | a local confirmation cue only (the view for that id is torn down by the `SpoonHidden`/`Spectate` that follow). **No score, no count, no inference** |
| `Spectate` | `view:hideAll()`, `camera:enter(p)` |
| `HuntEnd` | `view:hideAll()`, `remaining:hide()`, `camera:exit()`. The scoreboard is **Phase 6's** to render; this phase logs it and no more |
